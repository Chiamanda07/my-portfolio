# My Engineering Portfolio

A cute, bubbly portfolio for hardware engineering and software engineering.

## Features

- Light blue and beige visual theme
- Butterfly and bubble decorations
- Projects, experience, leadership, and contact sections
- Resume chooser with separate hardware and software PDFs
- Mobile-friendly layout
- Easy Netlify deployment

## Tech

- HTML
- CSS
- JavaScript

## Files to know

- `index.html` for page content
- `styles.css` for styling
- `script.js` for interaction behavior
- `fonts/` for local font files

## Resume files

- `Chiamanda_Hardware_Resume.pdf`
- `Chiamanda_Software_Resume.pdf`

## Notes

This project is a static site, so it can be updated by editing the files above and then redeploying to Netlify or pushing to GitHub.
